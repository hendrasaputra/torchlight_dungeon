Illustrations

A list of illustrations for the lore, with a prompt for each. The look follows three reference pictures: an old adventure-module page in pen and ink, a loose ink-wash scene, and a coloured comic-ink character. None of the references is copied; they only set the style.

How to use the prompts

Each illustration names a style (A, B, C or D). Write the prompt as: subject text, then the style block. Every subject is written from the lore, so the creatures and people are original designs; keep the last line of each style block ("original design...") in the prompt, since it keeps generators from drifting towards famous characters.

Suggested sizes: portraits 2:3 (for example 1024 × 1536), scenes and places 16:9 (1536 × 864), items, emblems and family plates 1:1 (1024 × 1024). Save the results as PNG in lore/art/ with the file names given here, then run ./build.sh: the build makes the web copies and puts each picture in its place on the lore pages, and it prints how many of the illustrations exist so far.

What every picture needs

Add these to every prompt, after the style block, so the set looks like one book:

Single clear subject, centred, with a little empty margin on every side. No text, letters, numbers, labels, captions, signatures, watermarks, borders or frames. Not a photograph, not 3D render.

The pages add their own frames, captions and labels, so the pictures must not.

Keep the recurring faces the same. These appear in more than one picture; copy the description word for word each time:

The four styles

Style A: pen and ink (old module page).

Black-and-white pen-and-ink illustration in the manner of a 1980s fantasy adventure-module page: fine crosshatching, stippled shadows, bold black areas, white paper showing through as highlights, hand-drawn line weight, slight paper texture. Dramatic light from one source (a torch or lamp), deep black shadows. No colour, no gradients, no text. Original design, not based on any existing game, film or book character.

Style B: ink wash (field sketch).

Loose black ink and grey ink-wash illustration on warm off-white paper: fast expressive brushstrokes, dry-brush texture, spattered ink, heavy black shadow masses, a few sharp pen lines for detail, figures small against big dark spaces. Monochrome, eerie and atmospheric, like a sketch made by torchlight. No text. Original design, not based on any existing game, film or book character.

Style C: coloured comic ink (character plate).

European comic-book illustration: confident black ink outlines with hatching in the shadows, flat and slightly textured colour like watercolour or gouache, limited warm palette (ochre, rust, teal, dusty pink) with one strong accent colour, low-angle heroic composition, characterful and a little humorous, detailed costume and gear. No text. Original design, not based on any existing game, film or book character.

Style D: old map and cutaway (plate in an atlas).

Hand-drawn fantasy map or cutaway diagram in brown and black ink on aged parchment: fine pen linework, hatching for slopes and rock, small pictorial symbols for towns, forests, mountains and doors, a compass rose drawn as a lamp with rays, empty scroll-shaped cartouches where labels would go. Seen from directly above (maps) or as a clean side section (cutaways). No readable text. Original design.

Use A for monsters, crypts and dread; B for places, legends and moments of mystery; C for the peoples, heroes, shopkeepers and anything with a personality; D for maps and plans. Emblems use A drawn as a heraldic badge.
